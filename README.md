## 🚀 Featured Projects
 
### 🔐 RevealQR: Secure Dynamic QR Shipping Label System
`React.js` `TypeScript` `Node.js` `Express.js` `MongoDB` `JWT`
 
A full-stack application that replaces personal information on shipping labels with dynamic, tokenized QR codes, reducing exposure of customer data during delivery.
- Reusable React + TypeScript components integrated with JWT-secured REST APIs
- Role and stage-based access control in an event-driven delivery workflow
- Automatic revocation of data access after delivery, plus audit logging
- 🌐 [Live Demo](https://reveal-qr.vercel.app/) · 🔗 [View Repository](https://github.com/AkankshaJais09/Reveal-Qr)
### 💸 Expense Tracker System
